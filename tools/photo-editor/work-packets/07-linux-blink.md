# Packet 07 — Linux Chrome/Blink parity

The Linux edition uses the shared editor `web/` unchanged. A Python `snap_blink` bridge
starts and supervises the Linux build of the native sidecar, implements the same logical
host adapter as Tauri, supplies native file/folder selection where available, and keeps
all approved paths inside the job scope. Chromium is presentation only; never process
full-resolution pixels or 16-bit TIFF data in JavaScript or browser canvas.

Package a Linux-native sidecar. A Windows or Linux binary is never expected to run on
macOS. There is no macOS build/support work; source compilation by users is their affair.

Acceptance runs the shared contract and golden-recipe suite against both hosts, compares
exports, kills/restarts the sidecar, closes Chromium mid-export, verifies cleanup and
confirms feature/control parity. README honesty must state which Linux hardware was
actually tested and must make no macOS compatibility promise.
