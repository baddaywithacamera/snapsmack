# Packet 05 — layer styles and masks

Add non-destructive stroke; drop/inner shadow; outer/inner glow; colour, gradient and
texture overlay; bevel/emboss; style ordering; copy/paste; enable/disable and presets.
Add gradient, radial, luminance and colour-range masks with feather, invert and live
overlay inspection. Styles and masks remain recipe data and render identically in
preview/export.

Acceptance includes edge/alpha golden fixtures, extreme parameter limits, scaled export,
group interactions and project round trips. Painted masks are a separate optional
follow-up only after profiling proves large-image brush updates can stay responsive.
