# SMACK DEALER

SMACK DEALER is the local launcher for SnapSmack administration and operations
applications. It launches TROLL BOOTH, CRONOMETER, LOG FLOGGER, TICKET WICKET,
and SMACK UP YOUR BACKUP. A missing application remains visible and disabled.

It does not grant permissions, pass credentials between applications, or use a
shell to launch them.

```powershell
python dealer.py
```
