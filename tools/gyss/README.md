# GET YOUR SHIT SORTED

GYSS is the local-first SnapSmack photo organizer. Version 0.7.20 uses native Qt
on Windows and shares profiles, protected credentials, and per-site libraries
with the rest of the desktop family.

The Library page is home. Sync a site, browse locally, arrange photographs, and
explicitly publish. GRAMOFSMACK work is on Grid; enrichment is on Images; shared
connection administration is deliberately last on Sites.
Sync opens the local photos in Sort when it finishes. Opening Sort later also
loads the selected site's saved library, including its downloaded thumbnails.
Sort lets you edit ALT text, hashtags and up to three colour swatches beside
title, caption, category, landscape/portrait/square orientation and colour/B&W classification. Select one or more Sort tiles to enrich their missing fields through the site's AI provider. GYSS warns about possible paid calls and can stop after the current photograph.
Publishing new detail fields requires a site with the matching GYSS API update;
the app keeps edits locally and says so if the site has not updated yet.

Build with `build.bat`. The stable executable is
`C:\snapsmack\gyss\GET YOUR SHIT SORTED.exe`.
