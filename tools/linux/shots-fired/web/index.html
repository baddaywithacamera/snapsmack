SHOTS FIRED — HELP

SHOTS FIRED is the fleet-wide scheduled-post calendar: it pulls the FUTURE-dated (scheduled) posts from every fleet site into one agenda so you can SEE the whole lineup and SHUFFLE it — move a post to a new day, spread a bunched week out, bump one. It does NOT create posts (that is SYBU / COLD SNAP); it only surfaces and reschedules what is already queued. A post with a future date is already scheduled — the site holds it and reveals it on its date. 1. LOOK AHEAD sets how far forward to look (14 / 30 / 60 / 90 / 180 / 365 days). 2. REFRESH pulls every site's upcoming posts into the day-grouped agenda; each site has its own colour. 3. MOVE… on a post opens the reschedule box. Type a new date (YYYY-MM-DD) and time (HH:MM, 24h), then MOVE POST. CANCEL sits apart from MOVE POST so a mis-click cannot move a post by accident. Sites are read from the shared profile store — a blog set up in SYBU / COLD SNAP appears here automatically. A site with no scheduling API deployed yet shows a note and is skipped until its server route is added.
