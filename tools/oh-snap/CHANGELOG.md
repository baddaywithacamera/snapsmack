# OH SNAP 0.3.1 — October 26, 2026

- Normal project choices are SMACKONEOUT, the shared GRAMOFSMACK / SMACKTHEMUP skin family, and SMACKTALK.
- GRAMOFSMACK packages declare both `carousel` and `smackthemup` compatibility. Connected SMACKTHEMUP skins use that same family.
- FEDISTRUCTURE is retained internally for older projects but removed from the normal new-project selector.

# OH SNAP 0.3.0 — October 25, 2026

- Build new schema-v2 skins from a fixed presentation-only template checked by the current CMS policy. Export the manifest, template, CSS and review notes through the normal signing/distribution workflow.
- Preview post, archive, landing and static-page layouts using snapshots rendered from that actual template. Safe Unicode fixtures, phone/tablet/desktop widths and preview navigation.
- AI sees the current CSS, starter markup and recent accepted conversation. Provider model IDs are configurable; Gemini no longer targets the retired 2.0 model. Clear timeout, invalid-output and unsupported-feature errors.
- Restore custom CSS and the selected history position when reopening projects. Save one-second recovery drafts and resume the latest draft from the start screen.
- Native project dialogs and awaited confirmations; cancelling a proposal or variable push does not apply it.
- Full CSS/image/layout design, with deterministic variable/range/asset validation. Additional JavaScript engines require separately reviewed template hooks; this build does not invent those hooks or accept generated server code.
- Skin folder, author and version controls. Connected-skin work remains a CSS study; export CSS and check the actual site before applying it.
- Release-build trait import repaired; version 0.3.0 is separate from older installed copies.
