# SNAP SLAPPER versioning

SNAP SLAPPER has its own version history. Its version must never be copied from
the SnapSmack CMS or from a CMS release tag such as `v0.7.586D`.

## Product stages

- `0.7.x` — current active development builds
- `0.8.x` — closed beta
- `1.0.0` — first stable public release

The next corrected SNAP SLAPPER build is `0.7.20`. The earlier displayed
versions `0.7.560` through `0.7.563` were numbering mistakes caused by mixing
the desktop application's version with the CMS release sequence. They do not
represent hundreds of SNAP SLAPPER builds and must not be continued.

Within a product stage, increment the final component for each packaged build.
A SnapSmack CMS release may carry a SNAP SLAPPER build, but the two version
numbers remain independent and should both be identified where useful.
