# SnapSmack desktop icon family

Midnight Lime application icons generated for the Windows launcher family.
Each PNG is the 1536px transparent master; each ICO contains Windows taskbar,
desktop, Start-menu, and Explorer sizes (16, 24, 32, 48, 64, 128, 256).

The original files are the ornate large-format artwork. `*-simple.*` is the
taskbar-optimized family with thick strokes, flat colour fields, and radically
reduced detail. SNAP HQ uses the simple family for shortcuts.

Generated with OpenAI's built-in image generation tool on 2026-08-31.

`snap-hq.*` is the mark for the local launcher formerly called THE HUB. Its
central aperture and four tool tiles distinguish the desktop headquarters from
the online hub/spoke role.
