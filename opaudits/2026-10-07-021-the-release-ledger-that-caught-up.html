1. Decision

The ledger records what happened instead of manufacturing a clean history. Versions 0.7.826D and 0.7.830D through 0.7.835D are declared gaps. They remain tagged historical candidates, but they were not standalone packages or deployments and must not be retagged or backfilled. Version 0.7.836D is the deployed baseline. The next development release is 0.7.837D.

Bundling several fixes into one numbered release is allowed. Every included fix must appear in the versioned changelog. That release must be packaged, deployed, and checked before work starts on the next numbered release.

The deployed 0.7.836D baseline also carried the work named by the unshipped 0.7.830D through 0.7.835D tags:

  • 0.7.830D: serve selected packaged masthead fonts from a publicly routable central asset URL.
  • 0.7.831D: restore GALLERIA's mixed-case masthead.
  • 0.7.832D: restore SQUARED STRAIGHT's as-entered lowercase masthead.
  • 0.7.833D: restore JIVE TURKEY's saved white card/viewer background and scrim settings.
  • 0.7.834D: bind compiled option CSS to the skin that produced it, restoring GAME ON's saved gutters.
  • 0.7.835D: restore PARADE's saved flag palette by accepting the established string-list palette contract.

At the time, the Smack Central packager offered only 0.7.834D through 0.7.836D. That three-tag display window hid earlier candidates; it did not prove they had been packaged or deployed. Packaging 0.7.836D therefore created a historical gap that must be declared, not retroactively filled.

4. Gate correction

The tracked newline-delimited ledger is append-only by policy and is merged with Smack Central's publication ledger. A declared gap consumes its identifier permanently without claiming a package. The 0.7.836D baseline satisfies the predecessor identity for 0.7.837D, while the server still independently requires 0.7.836D package history and active-fleet deployment evidence. No override or force path is added.

5. THE GRID trigram finding

Pre-strip THE GRID computed its trigram display model inside the skin. Its landing template queried snap_trigrams, derived each post's slot and orientation, chose trigrams/trigram-{id}-{L|M|R}.jpg when present, ran row backfill, and emitted phantom tiles for the remaining tail case. Those operations mixed legitimate presentation requirements with forbidden database and filesystem authority.

The replacement is a bounded CMS provider. The public repository returns published post covers plus trigram ID, slot, and orientation. The controller realigns the bounded result, resolves an existing public slice to a relative presentation path, suppresses framing only for a physical slice, and supplies tail phantoms. The skin receives prepared values and emits markup; it receives no database handle, SQL, request parsing, writes, or arbitrary filesystem access.
