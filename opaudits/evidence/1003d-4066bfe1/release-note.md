# SnapSmack 0.7.1003D

Source commit `4066bfe17e5cd7ff82798eaada214f03b4890c96`.

- COLD SNAP can publish mosaics with the photo sizes you set on the desktop. SnapSmack saves and renders those choices, while unweighted mosaics retain their original layout.
- The installer creates the database cleanly. Mosaic preview and saved gallery spacing use the same gap.
- Portfolio galleries can display native-aspect masonry or one full-width column. The gallery retains its authored order when shuffle is off.
- TRUE GRIT keeps original photo proportions. CHAPLIN restores its archive grid and controls. CHAPLIN, GALLERIA and TRUE GRIT centre mixed-height photos within their rows. ONYX repairs archive overflow at tablet width.
- NEW HORIZON restores classic archive controls and the optional calendar. ALFRED restores a Hitchcock-style masthead, centred navigation and reading column with the owner's logo and shared social dock.
- Navigation indicates the current page on supported skins. IMPACT PRINTER improves image-block spacing, and TELEGRAM correctly renders its template variants and caption controls.
- Community photo hearts remain available. The emoji picker and write route are retired. Historical reactions remain in the database.

Package creation, installation and the live fleet-after acceptance are separate steps following the release tag.
