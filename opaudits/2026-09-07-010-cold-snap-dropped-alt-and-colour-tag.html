1. Summary

The alt text you typed into the COLD SNAP desktop poster — the description that makes a photo accessible — went nowhere. So did the Colour / black-and-white tag. The site was ready to receive both; the desktop app just never put them on the wire.

2. What a human saw

You wrote a careful description for a photo in COLD SNAP, posted it, and the published image had no alt text and no colour tag. Nothing warned you; the post otherwise succeeded.

3. Root cause

The site’s posting endpoint accepted an alt value and a colour-mode value all along. The COLD SNAP desktop poster simply never included them in what it sent. Because the two ends were built at different times, “the server accepts it” was mistaken for “the field arrives,” and nobody had watched the whole path end to end.

4. Evidence at diagnosis

Posted images arrived with empty alt and colour fields even when they were filled in the app — and the server endpoint plainly supported both, which located the loss in the desktop sender, not the site.

5. What we did

All three COLD SNAP posting modes now send both fields: the solo mode sends alt and colour; the stacked mode gained a per-photo alt box sent for each image; the bucket mode carries alt on the media upload into ingest. Everything lands on the image’s own record, so a photo’s description and colour tag travel with it — offline and on the wire. The colour-mode column was also added to the canonical schema so it stops depending on scattered ad-hoc fixes.

6. Verified live

Confirmed fixed by Sean. Alt text and colour tag now travel with the image.

7. Eyeball next

Any other desktop tool or posting path where the receiving end accepts a field the sender might not actually be sending — the same whole-path check applies.

8. The doctrine this incident created

Test the whole path, both ends at once. “The server accepts this field” is not “this field arrives” — a sender that never sends it will pass every test that only checks the receiver. Watch a real value go in one end and come out the other.
