Bug Reports

Before filing a report, check BUGGER! — there's a self-diagnosis checklist there that fixes most problems without any back-and-forth. If you've worked through it and still have a problem, here's what to include: what you were doing, what you expected, what actually happened, your PHP version, your MySQL version, and the error message if there is one. Screenshots are fine. Stack traces from the error log are better.

If you have a GitHub account, open an issue there. If you don't, email works exactly as well.

Contributing

SnapSmack is open source. Code contributions aren't being solicited — if there's a bug, Sean will fix it faster and better once he knows about it. If you want to fork it and do your own thing, you're welcome to.

Skin submissions are a different matter — those are very welcome. One rule: third-party skins must be free. No exceptions, no premium tiers, no upsell. The project exists to give photographers a hand up, not to create a marketplace that charges them for tools they need.

If you don't code or design, telling photographers that SnapSmack exists is contribution enough.
