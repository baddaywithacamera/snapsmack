# SnapSmack governing principles

SnapSmack must adhere to these three principles, in this order:

1. **Ethics first**
2. **Security second**
3. **Function third**

Nothing below may be allowed to compromise what is above.

Accordingly:

- Functionality must never be used to justify weakening security or ethics.
- Security must never be used to justify compromising ethics.
- When requirements conflict, the higher principle governs the decision.
- A release that violates this ordering must not ship, regardless of schedule, convenience, or apparent functional benefit.
